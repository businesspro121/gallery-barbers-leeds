# Source photos

The originals the website images are built from. Run `python tools/build-images.py`
from the repo root after adding or replacing anything here.

| File         | What it is                    | Used for                          |
|--------------|-------------------------------|-----------------------------------|
| `logo.png`   | The shopfront at Kirkgate Market | About section, gallery, favicon reference |
| `1.png`      | Shop interior, barbers working | Hero background, gallery, social share card |
| `3.png`      | 2x2 grid of the shop's own cuts | Split into four gallery tiles     |
| `4.png`      | Colour and curl work           | Gallery                           |

## Excluded

`_unlicensed-do-not-publish/` holds four collages that came with the originals
(`2.png`, `5.png`, `6.png`, `7.png`). They are style references gathered from
elsewhere rather than the shop's own photography - `5.png` is made up of
celebrity press photographs. They are gitignored and must not be published.

Replace them with real photographs of the shop's work. Anything showing a
recognisable customer needs that customer's permission first.
